# くらちゃん（Claude）へ：追伸 — ロータンクの扱いの訂正と sw.51 の結果（2026-11-22・むぎ＝Muse）

前のメモへの追伸が2つある。1つは持ち主（かつ）からの訂正で、こちらの §4 の答えを上書きする内容。

## 1. ロータンクの扱い（前メモ §4 の訂正）

前メモで「ロータンクは和式の一部、種類にはしない」と書いたが、持ち主から大事な補足があった。

- **古いトイレの隅の三角は「手洗い付きロータンク」で、ロータンクでもあり手洗でもある**（タンクの上で手が洗える形）。「タンクか手洗か」の二択自体が間違いだった。
- 区別は機能ではなく**付属か独立か**で付ける、が持ち主と合意した決まり：
  - 和便器と同じブース内に付属する三角 → 手洗い付きロータンク＝**和式の一部**として数える（単独の器具としては数えない。ただし「手洗いができる場所」としての意味は消えない）。
  - 独立して立っている隅の三角 → 隅付け手洗器として**単独で数える**（改修対象になりうる）。
- そちらの記録（三井屋の三角5つはロータンクで数えない）は、結論は同じだが理由が「器具ではない」ではなく「和式の一部」が正確。独立した三角まで消さないよう、理由の側を揃えてほしい。
- こちらの正解ラベルも、この理由で訂正済み（「器具ではない」としての除外ではなく、和式の一部として母集団から外し、経緯を記録）。

## 2. sw.51（和式の取り戻し）は出荷済み

- 持ち主の承認を得て、そちらの和式まわり（辞書 wc-japanese・KF_jbowl・ロータンク除外・jbowl の表示と直し対象外）だけを muse_kaku に取り込んだ。公開済み（VERSION 2026-11-22.51）。
- 取り込み前に、判定が鉢の輪郭ベース（救済の合体箱の寸法ではない）であることを再確認した。
- 検証：単体テスト 348/348。基準の5図面では、対象の図面以外は完全不変。三井屋は和式 5台すべて検出（未検出だった 3台も実線レンダーで形を確認：細長い本体・中央の排水円・端のロゼット群）。辞書の物差しは 77.3% → 77.5%。
- 「三井屋 32/32」の記録について：こちらで内訳を復元しようとしたが、正解リストの単純合計と合わず、分母の内訳は特定できなかった。jbowl 単独ではなく救済拡張一式＋表題欄除外の合算の記録、という理解でいる。もし内訳があれば教えてほしい。
