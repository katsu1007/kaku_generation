# むぎ（Muse）へ：器具の拾い方と辞書のすり合わせ（2026-11-22・くらちゃん＝Claude）

かつに頼まれて、器具の拾い方（数に効く方）とシンボル辞書（符の表示）を揃えた。
お客さんの図面そのもの・正解の数はここに書かない。寸法と形の決まりだけ。

## 1. 辞書（js/symdict.js）に足した物

- **和式便器**（`id: wc-japanese`、`category: 和式便器`、`kind: 衛生器具`）
  - ルールのパターン1つ：短い方 200〜360mm・長い方 500〜800mm・長さが幅の 1.9〜3.5倍・曲線の割合 0.5 以上・閉じた形
  - `needs_features: ["arcShare"]`：**寸法だけ（器具の外形の箱）では当てない**。250×800 級の浅い箱（消火栓箱のテスト）と重なったため。線のかたまり（classifyCluster）でだけ当たる
  - 根拠：1つのレイヤーに壁も器具も描いた実図面（トイレ改修の現況図）で、持ち主のかつが実物を確かめた。鉢は細長い楕円、ブースの隅の三角はロータンク（レバー付き）で、便器の一部なので数えない
  - 洋式大便器の帯（幅 350〜490）とは短い方が重ならない
- `SAN_CATS`（椅子の文脈判定で使う衛生の種類）に和式便器を足した
- テスト：`tests/symdict.test.mjs` の最後に1件（275×655・曲線多めは和式便器、箱だけでは当てない）。`node --test tests/*.test.mjs` 331件通過

## 2. 拾い方（js/fixrescue.js＝器具の救済）に足した決まり

壁と器具が同じレイヤーの図面で、救済が拾う器具だけに効く。エンジン（old/index.html）は触っていない。

| 形 | 決まり | 付ける印 `how` |
|---|---|---|
| メーカーの細かい図の洋便器 | 線300本以上・曲線150以上・45〜65cm×55〜80cm・丸1つまで | `detail` |
| 和便器 | 細長い楕円の曲線のかたまりが1つで、全体の曲線の半分以上 | `jbowl` |
| 角の丸い四角の槽（1つ・中に排水口の丸） | 線の端どうしが付いて閉じた形、30cm以上 | `sk` |
| 同じ大きさの槽が60cm以内で並ぶ | カウンター1台（2ボウルなど） | `bowlrow` |
| 置き型の洗面器 | 40〜60cm×50〜75cm・丸2つ以上・鉢あり。並んでいても1台ずつ | `basin` |

数えない物：和便器から50cm以内の、斜めの線がある55cmまでの小さい物（隅のロータンク）、断面の斜線だけのかたまり（扉の枠）、四角の中の×（天井点検口）の線。

## 3. 符の表示と種類の直しの扱い

- `how` が付いた器具は、符の表示で寸法だけの判定より形の判定を出す（`project.js` の `symList`。`jbowl`→和式便器、`detail`→洋式大便器、`sk`→流し・SK、`bowlrow`・`basin`→洗面器、検出）
- `how` が付いた器具は、種類の直し（js/typefix.js）の対象にしない（手で直した器具と同じ扱い）。形で決めた物を、寸法と文脈の補正で上書きしないため
- 表・表題欄の中の器具（会社のマーク・空の枠）は、図面・3D・判定の一覧に出さない（`sheets.js` の `fixturesInRegions`。明細には前から入っていない）

## 4. 確かめたこと

- 正解付き25枚・基準のトイレ図面・実図面3枚：器具（見せる種類）が直す前と1つも変わらない
- 変わったのはトイレ改修の図面だけ。図ごとの数が、かつに教わった正解と全部合った

## 5. むぎに見てほしい所（まだ揃っていない）

- **600×1540 の一体型カウンター（2ボウル）**：拾い方は洗面台、辞書は寸法だけで「机・デスク（類似）」
- **500×753 の壁掛けの洗面器**：拾い方は洗面台、辞書は「流し・SK（類似）」。前に書いてくれた「SK重なり帯」の近く
- **ロータンク**：辞書に種類として足すか。今は拾い方の方で、和便器のそばの三角を消しているだけ。寸法（30〜40cm 角の三角）は隅付けの手洗器と重なるので、箱だけでは見分けられない
- 和式便器の帯（200〜360×500〜800）は1つの図面の形からしか決めていない。ほかに和便器の図面があれば帯を見直してほしい

正解は、かつか会社の人が確かめた物だけを使う。自分で作った正解で採点しない、の決まりはこちらも同じ。
