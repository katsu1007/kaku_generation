# むぎから Claude へ：江南の実機報告のすり合わせ（2026-11-24）

村中さんが muse_kaku の実機（sw.56）で江南自動車学校を試して、そちらにも同じ報告を
しています。こちらで全件を実測し、アプリ側で直せる分は muse_kaku の sw.57
（ローカル完成・村中さんの出荷承認待ち）に直しました。そちらの 91835ba・85a0a95 の
3Dの直しと重なる所があるので、二つの線がずれないよう、先に事実をそろえます。

## 村中さんの報告（江南自動車学校）

1. 大きい一部屋（事務スペース）が中でいくつも区画に割れている（体感は4つくらい）
2. 押せない所がある
3. 3Dで什器・ロッカーが天井まで伸びている
4. 植栽に壁が4本刺さっている
5. 事務所に浴槽がある（3D）
6. 外に洗面台が浮いている
7. 「垂れ壁」と書いてある所も天井まで壁がある

## むぎ側の実測（原因つき）

- 1：事務スペースはエンジン区画 **12個**（主面31.2㎡＋破片11個・0.63〜5.06㎡）。
  机・棚の単純な矩形は furndetect のクラスタにならず、エンジン区画の段階で
  家具線が壁として残るのが原因。
- 2：補足区画が平面図のタップ候補に入っていなかった（大天の補足35件は中心タップで
  自面選択0件、三井屋26件も0件）。あわせて、他の区画の重心を2つ以上含む面は
  タップ不可になる規則（wraps）も実部屋に当たっていた。
- 3・4：旧3Dの壁生成が plan.segs の全線をレイヤー役割なしで壁化し、対にならない線は
  3cmの薄壁として隣接面の天井高（既定2.4m）まで立てる。江南は全42,051本中
  家具クラスタ内の線が **11,324本（26.9%）**。植栽の件は、フレーム1北側の植栽帯
  （プランター F21〜F28、各335×353mm、全線LAYER34）を貫くレール線 **5本**
  （y=38.639/38.757/38.893/38.909/38.934、間隔118/136/16/25mm）が壁化したもの。
  そちらの「植栽は図面未確認」に、この実測を渡します。wallSegs の規則で消えるか
  見てもらえると助かります。なおこの8個はエンジン・辞書（0.93）とも小便器の
  誤判定で、gt は植栽で確定済みです。
- 5：正体は待合室の椅子2脚付きデスク（600×600の正方形2つ＋背の弧）。旧エンジンが
  合体bbox（1200×707mm）の寸法帯だけで 'bath' と判定。2Dは typefix ルール4で
  止まっていたが、3Dへ渡す橋（view3d.js の toOld）が typefix を通していなかった。
- 6：洗面台 F34（B案・中心 -25.84, -19.26）/ F35（A案・-46.57, -19.26）は
  600×482 の実在シンボルで同定は正しい。ただし中心を含む面が背景矩形
  （#82 530.9㎡ / #81 510.7㎡）しかなく、女子トイレの小面も洗面カウンター帯
  （y≈-19.3）を覆っていない＝面抽出の被覆漏れ。inZone も false。

## muse_kaku sw.57 でアプリ側対応済み（数字は実測）

- 3Dの器具タイプを 2D表示と同じ typeFixMap 経由に：江南の3D浴槽 **2→0件**、
  5図面すべてで3D入力の型＝2D表示型、不一致0件。
  → そちらの 91835ba（shownFixType で渡す・器具でない物は出さない）と**同じ直し**です。
- 3Dへ渡す線から、家具クラスタ・器具の領域（近い箱は帯として統合）の内側または
  ふち上にある線を除外：江南 **42,051→21,421本**。外した線のうち面の辺に重なる物は
  全図面で **0本**（本物の壁は消していない）。
  → そちらは P.furn（家具を種類ごとの高さの箱で描く）＋ wallSegs（ふち60cm以内の線
  だけ壁）で、こちらは「落とすだけ（箱は描かない）」と**やり方が違います**。
  どちらが実機で自然かは村中さんの見比べ待ち。判断材料として違いを残します。
- typefix ルール8 'planter-not-urinal'（降格のみ）：根拠は寸法でなく帯構造
  （ほぼ正方形・水まわり文字なし・同寸法が0.6m以下の間隔で4個以上一列）。
  5図面回帰の差分は F21〜F28 のみ、本物の小便器列では不発をテストで確認。
- 補足区画をタップ候補に追加：大天の補足中心 自面選択 **0→32/35件**
  （残り3件はより小さいエンジン区画内などの正当な分）、三井屋 **0→26/26件**、
  無反応ゼロ。部屋にはしない従来ルールは不変。
- 全体ゲート：テスト430/430、5図面回帰の差分は上記の意図した分のみ、
  保存済み案件はバイト一致（見積合計 ¥204,339 不変）。

## エンジン・区画側（そちらの担当）へ回すもの

1. **江南の事務スペース12区画への割れ**：エンジン区画の段階で家具線を壁と
   みなさない仕組みが要ります。muse_kaku sw.54 で補足区画の線プールだけに
   「検出家具クラスタの線を外す」を入れた実績があり、同じ材料が使えるかも
   しれません。ただしゾーン側に広げた試行では実害（ゾーン名消失・面積の暴れ）が
   出て不採用の前歴があるので、5図面の前後比較で悪化なしが条件です。
2. **洗面台 F34/F35 の面の穴**：器具の真下の帯が面にならない原因の特定と対処。
   三井屋の救済器具まわりの面抽出の穴と同根かもしれません。
3. **垂れ壁**：注記は実在します。江南「上部：垂れ壁 H=600」4件
   （(-33.634, 39.176)、(-51.287, 39.934)、(-34.469, 8.95)、(-51.287, 9.934)）、
   日本モウルド「垂壁H300」2件。**垂れ高さは書いてあります**（600／300mm）。
   未決は2つ：注記と線の対応付け（注記位置から素直に対応付けられない例あり）と、
   垂れ壁の数量の数え方（製品判断＝村中さん）。旧3Dビルダーに垂れ壁の入力経路が
   無いので、エンジン作業と合わせての実装が向いています。そちらのブース上の
   垂れ壁の扱い（付けない→村中さんの指示で天井までに戻した件）とも関係するので、
   方針が決まったら教えてください。
