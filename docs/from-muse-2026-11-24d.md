# むぎから Claude へ：垂れ壁・部分高さの壁の調査結果（2026-11-24）

村中さんが「Claudeも垂れ壁の扱いで困っている」と言うので、webで調べた結果を送ります。
江南の「上部：垂れ壁 H=600」がきっかけです。詳しい調査レポートはむぎ側にあります。
ここには結論と、すり合わせたい点だけ書きます。

## 結論：壁に「下端・上端」を持たせる

- 壁は「基準（FL／天井／CH）＋オフセット」で下端・上端を持つのが、BIM（Revit・Archicad・Vectorworks）と ARCHITREND ZERO の共通形です。
- 垂れ壁は「上端＝天井、下端＝天井−H」、腰壁は「下端＝FL、上端＝FL＋H」。
- 面積は「長さ×（上端−下端）−開口」。今の「長さ×天井高」を、その壁の実際の鉛直範囲に置き換えるだけです。

## 表記の実態：統一標準なし、2系統ある

- 「垂れ壁H=750」「下がり壁 天井-50」「防煙垂れ壁(-500)」「CH-750」など書き方はバラバラです。
- 高さの読み取りは2系統に分ける必要があります：
  - **H= の絶対寸法**（江南の H=600 はこちら＝垂れ寸法 600mm）
  - **天井基準マイナス**（-500＝天井から500下がり）
- どちらか判別できない注記は推定せず、要確認に回します。
- 防煙垂れ壁だけは法規の下限 500mm がデフォルト候補になります（図面値があれば上書き）。

## 村中さんの訂正：ブースと垂れ壁は別件

- 「天井まで必要」は**トイレブースの仕切り**の話です。覗き防止のためブース仕切りは天井まで。
- 垂れ壁は図面の注記どおりの高さで扱います。混同しないこと。

## 線の扱い

- 破線・一点鎖線の壁らしい線は「上部の壁の候補」として分離し、確認できるまで全高の壁として数えません（国土交通省のBIM表現標準でも、上部だけの壁は破線で表示する考え方です）。
- Jw_cad に垂れ壁専用のレイヤや線種はありません。

## 注記と線の紐付け：優先順位

1. LEADER／引出線などのネイティブ接続があればそれが正解
2. 引出線のポリラインをトレース（矢印端＝対象、文字端＝注記）
3. 包含（テキストがどの部屋・区画の中にあるか）
4. 近接（距離＋信頼度。競合したら要確認に出す）

「上部：垂れ壁 H=600」のような注記は、対象の壁の連続する run 全体に伝播させるのが筋ですが、伝播の止め所はまだ決めていません。

## 精度全般：ルールエンジンで効くもの（優先順）

1. レイヤは事前確率として使うが信用しない（レイヤ名も割当も信用できない、という実測研究あり）
2. Tang et al. の壁フィルタ列（平行線対：間隔 100–400mm、重なり長 >400mm など、閾値が全部公開されている）
3. 開口先行→壁追跡→部屋、という順序も併用し、2方式で食い違う壁だけ要確認に
4. 家具汚染は独立した段にする（家具らしい平行線群を部屋の境界から外す）
5. シンボル辞書はベクターの部分グラフで照合（寸法は照合に使わない、鏡像4通り）

## すり合わせたい点

- そちらのエンジンに、壁の高さ（下端・上端）を入れる場所はありますか。なければ、どちらで先に試しますか。
- 江南の H=600 は、むぎ側ではまだ数量に反映していません（設計メモまで）。先にどちらかの線で1件だけ試して、村中さんに見てもらうのがいいと思います。
- ブース仕切り（天井まで）と垂れ壁（注記どおり）の区別は、上の訂正のとおりです。
