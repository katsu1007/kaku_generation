## 1・2. 1レイヤーの図面の便器・小便器・SK（n2）→ 入れた（救済の中だけ）

- 本当の原因は決まりの帯ではなかった：n2 は部屋・外壁を**閉じた折れ線**で描いてあり、救済の「1.5cm 以内で重なる物をつなぐ」で、外壁の折れ線の箱に全部の器具が入って**1つのかたまり**になっていた（18m の箱で、分け直しの上限 12m を超えて分けられない）。4m を超える曲線の無い折れ線は器具の材料から外した → 便器4・小便器2 は今までの決まりで拾えた
- 外したら、重なった椅子の丸2つ（事務室）が便器と見られたので、**丸だけのかたまりは便器にしない**を足した
- SK：むぎの決まりの形の方（外の四角の中に、曲線の無い閉じた四角が片側 4〜11cm 内側・その中に 12cm までの丸・短い方 42〜50cm・長い方 44〜74cm）→ SK（how: 'sk'）。寸法だけでは決めない
- 結果：n2 器具 3/10 → 10/10。ほかの図面の器具は1つも変わらない（三井屋の34個も同じ）
- 簡単な記号の洋便器・小便器の新しい分岐（楕円の弧率・タンクの四角など）は、上の原因を直したら要らなかったので入れていない。むぎの数字は次に簡単な記号の図面が来た時に使う

## 2. n1 の SK → 入れていない

- n1 はレイヤーが分かれた図面で、救済ではなく読み取りの部品（エンジン）が、洗面カウンターと隣の SK を**1つの洗面台の箱**にまとめている。SK を切り出すにはエンジンの器具のまとめ方か、器具の線を後で見直す所が要る。エンジンは触らない約束なので、ここは止めた。器具の線（allSegs）から「カウンターの箱の端にある SK の形」を探して切り出す案はある

## 4. 器具が壁ぎわの便所で床が減る → 入れていない（測ったら悪くなる所が多かった）

- 試した形：区画のどれにも中心が入らない器具の箱で、隣の区画にかかる物の「箱の広さ − 区画と重なる広さ」を、その区画に足す（2.5㎡・3.6m まで）
- 正解の部屋がある10枚で ±2% 以内の部屋 48 → 49。n2 の男子便所 −5.4→−2.1% と良くなる所もあるが、**浴室 −6.5→+26.8%、調乳室 +1.0→+19.1%、給湯室 −1.3→+10.7%、湯沸室 +1.0→+17.8%、女子トイレ 0.2→5.9%、スタッフ室 0.2→6.3%** と足しすぎる所が多い（器具の箱が壁や隣の部屋にはみ出している、浴槽・流しの箱が区画の形より外にある、など）
- なので入れていない。むぎの (b) の「中に器具の中心が入る、部屋に囲まれた小さい所」を、箱ではなく区画のマス（読み取りの部品の捨てた小さい所）で取る形でないと、数字が安定しないと見ている。捨てた小さい所はエンジンの中にしか無いので、やるならエンジンから出してもらう所から
- b6_office_columns の −19%・−31% は、むぎの見立てどおり別の原因（箱を足しても −17.8・−26.2 までしか戻らない）
