# くらちゃん（Claude）へ：メーカー・競合の調査を共有します——sw.53 の出典と、まだ入れていない案（2026-11-23・むぎ＝Muse）

村中さんから「今日聞いたメーカーの出している物で、取り入れたら成長しそうな物は Claude にも共有済みだっけ？」と聞かれました。機能の方は sw.53 を取り込んでもらったので渡っていましたが、調査そのものは渡していなかったので、判断に関わる要点だけまとめます。数字は各社の公表値で、目標値と実測は混ぜないように書きます。

## sw.53 に入れた4件と、その出典

- **根拠ボード ← パナソニック「間取り図AI積算」の出力物**。見積書に加えて「間配りボード」「間取り図付き提案ボード」を出すのが出典です。パナソニックは2024年4月開始で自称「業界初」、利用はパートナー専用サイト（Webハウズ）経由のみ。「拾い41分→15分」は自社の積算部門での平均として公表された数字で、目標値とは書かれていませんが第三者検証でもありません。2026年4月にはスマホ撮影版「写真de AI積算」（誰でも無料、約5分で概算見積）まで広げています。
- **標準の仕上げプリセット ← LIXIL／KK Generation の「会社ごとに保存した仕様」**。LIXILの「AI見積システム」（2026-11-17発表）は自社開発ではなく、KKGのカスタマイズ型SaaS「積算AI」をLIXILの商材仕様に作り替えて既存ツール CRASFL に組み込んだ物です。建築会社ごとの詳細仕様を保存して認識結果を割り付ける設計が、プリセットの出典。入力はPDF・画像中心で、ラスター認識が濃厚（CADベクターを直接読む証拠は公開情報に無し）。「積算時間 約62%削減」は標準物件を想定した**目標値**（40分→15分）で実測ではありません。利用はCRASFLのパートナー企業のみ、価格は非公表。
- **出どころ表示 ← 「数量の根拠をたどれる」表示のパターン**。海外でも同じ方向があり、中国 Glodon の Cubicost は数量がモデルと計算式にたどれる作り、米 Mirage は数量ごとに図面・詳細・仕様への参照を付けます。むぎ側は「図面から／図面＋手直し／手入力」の出所表示として実装しました（向こうの出どころ表示と重なるので非表示、という 820659d の判断はそのままで大丈夫です）。
- **辞書の学習 ← システムズナカシマ「拾いの匠NX」の「学習のループを製品に入れる」発想**。拾いの匠NX（2026-06発売）はJIS規格の図面記号を学習したAIが設備記号を認識する製品で、むぎ側はチェックパックで村中さんと外で回していた学習を、「自分の辞書＋形の署名」として製品の中に入れました。

## 全体像（判断に関わる事実だけ）

- 日本のメーカーで図面読み取りを公式に出しているのは、実質 LIXIL とパナソニックだけです。TOTO・大建工業・ノダ・永大産業・ウッドワン・タカラスタンダード・クリナップ・三協アルミは、品番や条件を選ぶ従来型のWeb見積のみ。KKG経由は他にサンゲツ（カスタマイズ実装の事例までで、製品としての提供は未確認）とアルインコ（開発完了、2027年春頃の市場投入目標）があります。
- 世界の大手建材メーカーには、図面読み取りの積算製品は**見つかりませんでした**（Saint-Gobain、Knauf、ROCKWOOL、Hilti、ASSA ABLOY、Schneider Electric、Siemens、TOTO海外、Kohler 等。あるのはBIMライブラリと選択型コンフィギュレーターのみ）。「見つからなかった」は不存在の証明ではない、という留保付きです。
- 自動拾いの主戦場は米国のプラットフォームで、Togal.AI（月299ドル／人）が代表格。精度97〜98%は同社の主張で、裏付けに一番近いのはカンザス大学の研究（同社資料経由）による「手作業の拾いより76%速い、精度は同等」。他社も含め、数字はほぼ全部が自社主張で、独立した精度検証は見つかりませんでした。主流はPDF（ラスター）読みです。
- CADのベクターをそのまま意味読みする物は少数派です（英 Kreo＝DWG/DXF等をネイティブ読み、中国 Glodon＝DWG認識→BIMモデル化して数量）。**JWW を読む製品は世界のどこにも見つかりませんでした。**
- KKG式の「メーカーごとにエンジンを作り込む」モデルは海外にありません。一番近いのは米 Higharc で、建材の「メーカー」ではなく流通業者ごとにSKUとルールを割り付ける形です。
- 内装・改修に特化した物はほぼ空きで、はっきりした内装専用は Glodon の **DecoCost**（2026、中国）だけでした。天井・床・壁の仕上げ認識、部屋の境目からの自動フィットアウトまでやります。

## まだ入れていない案（1件だけ挙げます）

DecoCost にある「**図面なし改修の概算見積**」です。図面が無い初期段階の改修でも、写真などから概算を出す導線を持っています。KAKUの改修ニッチなら「図面が無い現場でも、部屋の大きさ＋標準仕上げで概算を出す」形に応用できる候補だと思っています。まだ設計はしていません。村中さんがやる気なら、むぎが設計を書きます。

## 差別化の置き所

「JWWベクタ読み＋改修内装＋根拠を説明できる＋日本で一般販売」という組み合わせは、調べた範囲では何ともぶつかりませんでした。近い物はどれも2つ以上欠けています（Kreo はベクター読みだが新築向けの汎用、DecoCost は内装だが中国市場でBIMモデル化が前提、Higharc はSKU割り付けだが米国の新築住宅で企業向けのみ）。
