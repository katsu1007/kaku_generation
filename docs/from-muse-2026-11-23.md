## 2. SK を見落とす（n1・n2）

### どこを直すか

救済（`js/fixrescue.js`）の SK の拾い方と、今の「幅40cm・奥行37cm以上は全部SK」というサイズ決まりの関係の整理です。

### 実測の前提：SK はサイズでは決められない帯がある

- 実在の SK（TOTO SK322）は **560×456**（バック付き・槽内幅357）。SK の幅レンジは 525〜720×奥行 450〜460（REFERENCE 実測）。
- ところが洗面器単体も 500〜600×450〜550 で、**幅500〜600×奥行450前後は SK と洗面器が完全に重なる「サイズ無効帯」**です。
- なので「幅40cm・奥行37cm以上は全部SK」は広すぎます（洗面器を全部 SK にしてしまう）。サイズは候補に上げる所までで、決定は形でやるのが筋です。

### 決まりの案（形が先）

n1・n2 の SK（外の四角 500×450＋内側の四角 400×340＋排水口の丸＋水栓の丸）に対して：

| 条件 | 値 | 根拠 |
|---|---|---|
| 候補の箱 | 短辺 420〜500・長辺 440〜740 | SK322 の 560×456 と n1/n2 の 500×450 の両方を覆う。**一部 案（要測定）** |
| 内側の形 | 内側最大閉形が **四角**（弧率 ≤0.35） | **実測**：ジェイテクトの SK の内側閉形の弧率は **0.25**。小便器・洗面器の楕円ボウルは 0.68〜1.0。内側が「楕円か四角か」が SK と洗面器のいちばん効く分かれ目 |
| 内側四角の入り込み | 外形から片側 40〜110mm 内側 | n1/n2 は (500−400)/2＝50、(450−340)/2＝55。SK322 は槽内幅357で (560−357)/2≒100。深い槽ほど入り込みが大きい。**端の値は案（要測定）** |
| 排水口の丸 | 内側四角の中に丸が1つ | n1/n2 の形そのもの。洗面器のボウル（楕円）との差別化の補助 |
| 単体であること | カウンターの並び（同寸法の繰り返しや台と一体）に入っていない | 下記の流し台との判別と合わせて、SK は単体・壁ぎわ・SK室／用具入れ／PS 近傍という文脈が実測の特徴（REFERENCE §12） |

サイズ決まりとの関係の提案：

- 「幅40cm・奥行37cm以上は全部SK」は **候補上げ専用に格下げ**し、上の形の条件が揃った時だけ SK と確定する。
- 形が測れない（内側閉形が取れない等）場合は SK と決めず類似どまりにする。寸法だけで SK に確定させる今の動きは、サイズ無効帯で洗面器を巻き込むので止める方が安全です。

### 他の図面で間違えそうな所と、防ぐ条件

- **洗面器**：内側が楕円（弧率 0.68〜1.0）なので内側弧率 ≤0.35 で分かれる。鏡・化粧台の囲みがあれば洗面器側（REFERENCE の判別）。
- **流し台（キッチン）**：正直、ここが SK との判別でいちばん弱い所です。流し台の槽も四角い内形を持ちます。防ぎ方：(1) 流し台は横長（長辺が大きい）かコンロの丸（バーナー）を持つことが多いので、長辺の上限とバーナー丸の有無で外す。(2) SK は単体・壁ぎわ、カウンターの続きに入っていたら流し台側にする。(3) それでも分かれない物は類似どまり（SK とも流し台とも確定しない）。
- **ジェイテクトの SK（F21–23）**：実測では仕切り線が多く（99本、カウンター列と一体の描かれ方）内側弧率 0.25 で、今回の小便器・洗面器分岐からは仕切り線と内側弧率の両方で正しく外れています。新しい SK 分岐を入れる時はこの3台が SK のまま動かないことを必ず確認してください。

### 直ったかの確かめ方

- n1：洗面カウンターの隣の SK が拾えること（隣の洗面カウンターは洗面のまま）。
- n2：1レイヤー側の SK が拾えること。
- 実図面：三井屋の SK 1台（34/34 の内訳に入っている物）が SK のまま、ジェイテクト F21–23 が SK のまま、5図面の洗面器が SK に裏返らないこと。

## 3. 横に並んだ「現況図」「改修プラン」を分ける（n3）

### どこを直すか

`js/reader2/index.js` の `splitBands`。今は「図枠の左端（幅の1割以内）にある縦の見出し列」専用です。横並び版を、縦版の鏡像として足すのが素直だと思います。

### 決まりの案

1. **見出しの位置**：見出し（`BAND_LABEL` と同じ語：現況図・既存図・改修前／後・計画図・プラン○・○案）は図枠の中・表と表題欄の外にある短い横書き文字で、**各図の下**にある。縦版の「x が左端1割以内」の代わりに「見出しの y がそろった横の列」を探す：y の差が 1m 以内（縦版の列そろえ 1m の鏡像。**案（要測定）**）で、x が 1m 以上離れた見出しが2つ以上。
2. **境目の縦線**：縦版が「幅の6割以上の横の長い線」を境目にした鏡像で、2つの見出しの間にある **高さの6割以上の縦の長い線**があればそれを境目にする。無ければ、後述のすき間か中点。
3. **図と図の間のすき間**：建物の輪郭同士の間に、線がほとんど無い縦の帯があること。帯の幅の下限は **案（要測定）**（n3 で実測して決めてほしい。目安として 1m 以上）。
4. **同じ形の繰り返し**：左右に、大きさが近い建物輪郭の箱が2つ並ぶこと（現況と改修は同じ建物なので輪郭がほぼ同じはず）。見出しだけ・すき間だけより、この「似た輪郭が2つ」が当たった時がいちばん確かです。
5. 分けた後の `kind`（now/plan）の付け方は縦版の `kindOf` と同じ。既存の仕組み（`sheetsOf`：現況と改修が両方ある図面では現況は最初「使わない図」）にそのまま乗るので、**分けられさえすれば、現況図の器具が見積もりに二重に入る問題は追加の仕組みなしで直ります**。逆に言えば、分割が完璧でなくても（境目が多少ずれても）「現況」と名の付いた図を `kind: 'now'` で返せれば、二重数えの害は先に止められます。

### 他の図面で間違って割れない条件

- **三井屋**：見出しは左端の縦列なので、まず縦版 `splitBands` を先に試し、縦版が分けた図面には横版を当てない（三井屋が今の3段のまま変わらないことが確認条件）。
- **日本モウルド**：図は1つ＋表・表題欄。防ぎ方：(1) 見出しは表・表題欄の領域（skip）の中にある物を数えない（縦版と同じ skip の使い方。仕上げ表の中の「改修後」の語を見出しにしない）。(2) 見出しが2つ以上 **かつ** 似た輪郭の箱が2つ、の両方が揃った時だけ割る（片方だけでは割らない）。
- 図枠が複数ある図面（階ごと等）は、今の `sheetTitles` の図枠単位の処理が先にあるので、横版は「1つの図枠の中」だけで動かす。

### 直ったかの確かめ方

- n3：図が2つに分かれ、左（現況）が `kind: 'now'` で最初は使わない図になり、現況側の器具が見積もり・器具数から外れること。部屋 2/4 → 4/4、器具は改修側 13/13 のまま。
- 三井屋：今の3段分割（現況・プラン③・プラン⑤）と器具の数え（34/34 の内訳）が変わらないこと。
- 日本モウルド・大天・江南・ジェイテクト：図の数が変わらないこと。

## 4. 器具が壁ぎわの便所で床面積が少し減る（n2・n3）

### 前提と、今ある仕組み

持ち主の決まりは「器具・家具の下も床」。アプリ側には既に `roomHoles`（`js/drawing.js`、部屋にまとめた区画の中の「穴」を床に足し戻す仕組み）があります。ただ今回の減り方は、穴として残らず **区画そのものが器具の形に削れて**いる見込みなので、`roomHoles` の対象（どの区画にも入らなかった所）から漏れている可能性があります。まず n2 で「減った分が、穴として残っているのか／区画の形自体が削れているのか」を切り分けるのが先です。

### 決まりの案

**(a) 読み取り側**：壁と同じレイヤーにある器具の輪郭線を、区画の境目として扱わない。——理屈は正しいのですが、1レイヤー図面では「器具の線」と「壁の線」は同じレイヤー・同じ見た目で、線の段階では区別が付きません（むぎ側でも壁線分離の試行をして、便器ブースの壁と器具の縁が同一直線上で分けられないことを実測済み）。**読み取り側の全面対策は勧めません。**

**(b) アプリ側の足し戻し（推奨）**：`roomHoles` の考え方を広げて、区画の形が削れている場合も足し戻す：

- 対象：部屋（または部屋にまとめた区画の集まり）に接する／囲まれた小さい領域で、
- **中に、認識できた器具・家具クラスタの中心が入っている**こと（これが決め手の条件）、
- 広さの上限以下であること：**案（要測定）**。器具1台の占有は大きくても 1.5㎡ 級（カウンター類まで見て 2㎡）が目安。n2 の減り幅（男子便所 −5.4%）から逆算した穴の実面積を測って決めてください、
- その領域自体に部屋の名前・部屋判定が付いていないこと。

### 間違って足さない条件（パイプスペース等）

- **パイプスペース・シャフト**：中にあるのは配管で、認識できた器具・家具クラスタは入っていない → 「クラスタの中心が中にある」条件で外れます。これが (b) の安全弁の本体です。
- **便所のブース**：ブースの中には便器が入っているので上の条件に当たってしまいます。ただしブースは通常、便所の区画の一部か、便所にまとめる対象の小さい区画なので、「部屋にまとめた集まりの中の穴」として扱う範囲では害になりません。ブースを独立した部屋として数えている案件で足し戻しが走らないよう、「部屋判定が付いた区画には足さない」を条件に入れてください。
- 上限を超える大きい領域は足さない（本物の小部屋の可能性が上がるため）。

### 直ったかの確かめ方

- n2：男子便所 −5.4%・女子便所 −2.8% が ±2% 以内に入ること。n3：男子トイレ 約−3.5% が ±2% 以内。
- 実図面5枚：今合っている部屋の広さが変わらないこと。特にジェイテクト・三井屋の便所（今は合っているはず）で、足し戻しが余計に走って広さが増えないこと。

- **約束できること**：本物の浴槽の署名は輪郭実測で取れています——①輪郭そのものの幅 ≥580、②リム線が四周を一様に約70mm内側で閉じる、③排水口は端寄り（長辺方向の約9%・φ44）。洗面カウンターは「同寸法のボウル面が2枚並ぶ」物で、②のリム（全周を1つの内形として閉じる）を満たさないので、この署名では浴槽になりません。
