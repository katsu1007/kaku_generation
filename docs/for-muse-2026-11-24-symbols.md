# くらちゃんからむぎへ — Web のシンボル（器具・家具の図形）の出どころ調べ（2026-11-24）

かつに「Web からシンボル探しを深掘りして、むぎに渡すようにまとめて」と頼まれた。辞書（`js/symdict.js`）を広げる時に、**どこの物なら使ってよいか**を先に揃えたい。調べたのは 2026-11-24。決まりは変わることがあるので、入れる前にもう一度ページを開いて確かめること。

## 0. 前提（今の決まりのおさらい）

- 辞書に持つのは**形の特徴だけ**（寸法・縦横比・円弧の割合・内側の閉じた輪・分割線など）。元の図形の線は持たない・配らない
- KAKU は**売る可能性がある**ので、「非商用のみ」の物は使わない（特徴を測るだけでも、出どころの決まりに触れないかが分からないので、やめておく）
- 正解は、かつか別の担当が作った物だけ。Web の素材で自分で点数をつけない（素材は「辞書の帯を決める材料」まで）

## 1. 使えそうな物（商用でもよい・または公の資料）

## 2. 使わない方がよい物（理由つき）

| 出どころ | 中身 | 決まり・理由 |
|---|---|---|
| **FloorPlanCAD**（ICCV 2021） | 実際の図面 15,000 枚超を線ごとに注釈。家具 11 種（ソファ・ベッド・椅子・机・洗面 sink・浴槽 bath など）・設備 6 種（浴槽・**和式便器 squat_toilet**・**小便器 urinal**・便器・エレベーター・エスカレーター）ほか | **CC BY-NC 4.0（非商用）**。2023年1月にプロジェクトは終了 |
| **ArchCAD-400K**（2025） | 5,538 枚の図面・41 万の区切りを注釈 | データは申し込み制で**非商用のみ** |
| **CubiCasa5K** | 5,000 枚の間取り画像（主にフィンランド）・80 種類 | **CC BY-NC-SA 4.0**。しかも画像（線ではない） |
| **メーカーの CAD**（TOTO・LIXIL・パナソニック・シャープなど） | 便器・洗面器などの実物の図 | 著作権はメーカー。パナソニックは「複製・加工して第三者に提供・販売することを禁止」、シャープは「無断で複製・転記できない」。**辞書の材料にしない**（実際の図面の中にメーカーの図が入っているのを、特徴で見分けるのは今まで通り） |
| **建築パース.com**（メガソフト） | 人物・家具・住宅設備の DXF | 紹介記事に「商用利用は禁止」とある（運営元のページでは未確認） |
| **CAD-DATA.com**（投稿型） | 投稿者が作った素材 | ダウンロードした物は「利用者が作る図面・パース・資料に貼り付ける」ためだけ。辞書を作る材料にはならない |
| **QCAD のパーツライブラリ**（建築 約600） | DXF の部品 | アプリは GPLv3。部品集の決まりは**まだ確かめていない**。確かめるまでは使わない |
| Jw_cad 用の有料の設備図形（配管継手など） | 配管の継手・弁 | 有料・配管向けで、器具・家具の辞書には合わない |

※ FloorPlanCAD の**分類の名前**（和式便器・小便器・洗面・浴槽を分けている、壁・カーテンウォール・手すり・椅子の列を「数えない物」にしている）は、考え方として参考にしてよい（名前の並びは事実）。データは触らない。

## 3. むぎに頼みたいこと

1. **draftsperson の「License & FAQ」を読んで**、帰属表示が要るか・特徴だけ測って使ってよいかを確かめる。よければ、便器・洗面器・掃除流し・小便器の平面を DXF にして（むぎ側で変換）、今の辞書と同じやり方で特徴を測る。**日本の器具と大きさが違う物は、帯を広げすぎない**（日本の物で外れが増えたら入れない）
2. **略記号のルール**（1/100・1/200 の簡単な記号）を辞書に足す案を考える。平面表示記号の表に載っている「和式大便器」「洋式便座」「小便器一般（隔板つき）」「洗面器・手洗器」「浴槽」「パイプシャフト」「改め口（点検口）」を、形の決まりの言葉で書く。今の救済（`fixrescue.js`）の「四角の中の×＝天井点検口を外す」とも揃える
3. **寸法の帯の出どころを辞書の注に書く**（JIS A 5207 の洗面器、自治体の機材標準図の年度など）
4. **QCAD の部品集の決まり**と、前に「商用利用可・帰属不要」と確かめた **nasji.com** をもう一度見る（売る前の確認）
5. 足した後の確かめ方は今まで通り：正解付き25枚＋実図面5枚で、器具の数・種類が悪くならないこと（くらちゃんが回す）

## 4. 今回のテスト（AI が作った30枚）との関係

AI が作った30枚は英語の図面で、器具は `A-SANI`・`A-FIXT` レイヤーの簡単な形だった（`docs/for-muse-2026-11-24-aitests.md`）。上の 2 の略記号のルールができれば、こういう簡単な形の器具も拾える見込み。ただし 30枚には正解が無いので、点数づけには使わない。
