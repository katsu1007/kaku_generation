### (b) A-SANI/A-FIXT の器具が検出0件だった件 — 実測で切り分けた
z3/07（水回り詳細、ラベル隣接で同定確実）の実測：

| ラベル | 形（mm換算） |
|---|---|
| BATHTUB | 矩形 1000×1200 ＋ 内楕円 800×440 |
| WC | 矩形 500×600 ＋ 内円 φ240 |
| BASIN | 矩形 600×500 ＋ 内楕円 440×264 |
| SHOWER | 矩形 1000×500 のみ |
| FD | 円 φ120 → **床排水口**（辞書に無かったので新カテゴリで登録） |

拾えなかった原因は3つ：
1. 上流（レイヤー・単位）で器具として届いていない分 — そちらの管轄。
2. **実測の「机」パターン（508×609.6）に 0.984 で取られて「机・検出（誤り）」になっていた**。
   既存の衛生パターンは「全体の円弧の割合 ≥0.14」前提で、矩形＋ボウルの描き方（円弧0）には当たらない。
3. ボウルの弦が「分割線」に数えられる（WC 24本・BASIN 36本）ため、「分割線≤2」の形証拠の分岐が発火しない。

辞書側の対応（ゲート通過済み・パッチに入れた）：
- 洋式大便器に「矩形外形＋ボウル（簡略記号）」、洗面器に「矩形カウンター＋ボウル（簡略記号）」を追加。
  z3/07 の2クラスタは「類似：洗面器 0.990」になり、誤った机・検出は消える。
- ただし 500×600 級では洋式と洗面の外形が同じで分離できない。**本命はコード側の分岐**で、
  内側の形の縦横比が実測できれいに分かれる（WC の内円＝縦横比1.07、BASIN の内楕円＝1.67）。
  案：「外形は矩形＋内側の閉じた形が1つ」で、内側の縦横比 ≤1.25（かつ短辺180〜320）→ 洋式寄り、
  ≥1.4 → 洗面寄り。**条件に分割線の上限を入れないこと**（上の3. の理由）。実装はそちらの分担でお願いしたい。
- 素の矩形だけの器具（z3/01 の浴槽 900×700 等）は形では同定不能。レイヤー＋ラベル文脈はエンジン側の仕事として切り分けた。
