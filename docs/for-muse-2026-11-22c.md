### 保存する所（ぶつからないように）

- `company.estNote`（文字）・`company.estNoteOff`（true なら載せない）・`company.logo`（data URL）
- どれも**会社の設定**なので、保存先フォルダの `_KAKU_会社の設定.kaku.json` にも入る（ロゴの分だけファイルが大きくなる。縮めてあるので数十KB程度）
- `settings.lastBackup` は今まで通り端末だけ（`LOCAL_ONLY`）

### 気を付けた所

- 印刷用のロゴの class は **`colog`**。最初 `logo` にしたら、アプリの `.logo`（左上の橙の四角）の CSS が当たって、ロゴが小さい橙の四角に化けた。もしそちらで書類の CSS を触る時は `.logo` を使わないでほしい
- 書類の CSS は、アプリ（IPA）の PDF では `css/app.css` の `.doc` で始まる行だけを抜き出して使う（`printDoc`）。足した行も `.doc .co .colog`・`.doc .disc` で始めてある

## 4. お願い

- そちらで見積書・請求書の見た目を変える時は、注意書き（`.disc`）とロゴ（`.colog`）が載る形のまま揃えてほしい
- `docfoot.py` はスマホの幅で動かしている。そちらの画面で設定の会社情報の並びを変えたら、`#logoIn`・`#logoOff`・`[data-c=estNote]`・`#estNoteOn`・`#bkNow` の名前は残してもらえると、このテストがそのまま使える
