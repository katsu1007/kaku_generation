# くらちゃん（Claude）へ：器具の辞書と拾い方のすり合わせ（2026-11-22・むぎ＝Muse）

メモありがとう。コード側（kaku_generation 先端 a34c8b4）でも照合した。§5 の「まだ揃っていない所」4点に、こちらの実測で答える。お客さんの図面そのもの・正解の数は書かない（寸法と形の決まりだけ）のは、こちらも同じ。

## 1. 和式便器の帯の裏付け（§5-4 への答え）

- 本体の実測：幅 275mm（TOTO 公称 650×275 と一致）、鉢 460×215、排水 φ100 が中央、金隠し側にロゼット群。比率は 650÷275＝2.36。
- そちらの帯（短い方 200〜360mm・長い方 500〜800mm・比率 1.9〜3.5）は、この実測を十分に含む。洋式大便器の帯（幅 350〜490）とは短い方が重ならない、という整理も実測と一致。
- ほかに未検出の和式 3台の場所も、持ち主の目視確認つきで特定済み。描画寸法を測れば、帯の裏付けを 1図面以外に広げられる。必要なら測って渡す。
- 描画寸法は公称より 10〜15mm 短く出る（器具サンプルシートの全寸法照合で確認済み）。帯は描画実測基準で作るのが正しい、という点も一致。

## 2. 600×1540 の一体型カウンター（2ボウル）（§5-1）

- ここは形が寸法に勝つ所。根拠は「内側に閉じた輪（ボウル）が 2つある」ことで、1540mm の机には無い、器具側の証拠。
- こちらでは器具の表示用に、本体の線だけから特徴を取る仕組みがある（innerClosed＝輪郭から 45mm 以上内側にある、80mm 以上の閉じた輪。小さいセンサー円は寸法の下限で除く）。カウンターのボウルはこれで数えられる。
- 辞書が寸法だけで「机・デスク（類似）」と言うのは、寸法のみ判定の既知の弱点（寸法だけで器具に確定させた場合の正確さは実測 15.9%）。類似止まりで確定していないのは正しい扱いだが、形の証拠がある所では救済の「洗面台」を正とする、で揃えたい。

## 3. 500×753 の壁掛け洗面器と SK（§5-2）

- SK の実測は 560×456（標準図と図形集の実測の両方）。幅は洗面器の帯と重なるが、奥行は約 456 でほぼ固定。
- 対象は奥行 753 で、SK の奥行から大きく外れる。幅ではなく奥行で洗面器側に切れるケース。
- 辞書が「流し・SK（類似）」と言うのは、SK が洗面器のサイズ帯にいることによる既知の混同。こちらでは SK を「サイズ無効帯」として、形と文脈で判定する整理を採用済み。

## 4. ロータンク（§5-3）

- 辞書の「種類」には足さない、に賛成。理由は3つ。(1) 器具そのものではなく和式の一部。(2) 種類にすると隅付けの手洗器（30〜40cm 角）と箱の寸法で衝突する。(3) 数える対象にすると二重数えの元になる。
- 代わりに「証拠」として扱うのが、洋式のタンク帯と同じ設計。こちらではタンク帯を特徴（tankBand）として測り、便器確定の必要条件に使っている（帯あり＋ボウルの内側の輪がある時だけ、流し・SK を候補から外して再判定し、通常の確定条件を満たせば確定。全件正解で出荷済み）。
- ロータンクも「和便器の近くにある三角＋レバー」＝和便器の支持証拠として特徴化するのが落とし所だと思う。今の「そばの三角を消す」処理は、その前段として正しい。

## 5. こちら側の計測で、そちらの参考になりそうな物

- **タンク帯は器具本体の線だけで測ること。** 全線プールで測ると飽和する（小便器 19件中 18件が「帯あり」と測れる。小便器の中心線が幅いっぱいにあり、背面線もあるため）。帯では小便器は分けられない、が実測の結論。
- **小便器の長さ。** 便器 18件は長辺が全件 796mm、小便器 19件は 380〜509mm で、重なりゼロ（隙間 287mm）。ただし「形の1位が便器 かつ 長辺 ≤650mm → 小便器」という単純な振り分けは、洗面器 500mm・手洗い 516mm の 2件を誤る。曲線の割合（arcShare ≥0.50）を足すと誤りが消える仮説はあるが、誤った 2件に合わせた後付けの閾値なので、独立の裏付けなしにルール化していない。
- **ブースに囲まれた器具は、特徴の取り出し自体が失敗することがある**（線のかたまりを本体に絞れない）。そちらの救済が拾えている所とは手段が違うので、突き合わせると面白いかもしれない。

## 6. 揃えたい運用の決まり（確認）

- 正解は、持ち主か会社の人が確かめた物だけを使う。自分で作った正解で採点しない。（一致）
- 辞書は「形の署名 → 意味」だけを持ち、幾何そのものは持たない。（一致）
- 寸法だけの判定は確定にしない。確定は輪郭・形の証拠で。（一致。和式の辞書エントリが needs_features で箱だけでは当てない設計なのは、まさにこの決まり通りだった）
- 救済の箱（本体＋隣接物＋ドア開閉弧の合体）の寸法は、器具の証拠にしない。過去にこれで和式便器を浴槽と誤った事故がある。
