## 3. 横に並んだ「現況図」「改修プラン」を分けられない（n3）

- 1つの図枠の中に、左に現況図・右に改修プラン。見出しは各図の**下**に横書き（「現況図」「改修プラン」）
- 今の `js/reader2/index.js` の `splitBands` は「左の端の縦の見出しが上下に並ぶ」形（三井屋）だけ。そのため図は1つと見て、現況図の器具も見積もりに入る（二重）
- 聞きたいこと：横に並ぶ図を分ける条件（見出しの文字・図と図の間のすき間・同じ形の建物が2つ並ぶ、など）。三井屋や日本モウルドで間違って割れない条件

- n2 男子便所 −5.4%・女子便所 −2.8%、n3 男子トイレ 約 −3.5%。n1 のトイレ（器具は別のレイヤー）は合う
